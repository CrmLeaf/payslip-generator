One file · no build step · nothing leaves the page

Payslip Generator

Compliance-ready payslip PDFs with your company branding.

payroll.min.js is not on the page

It is shared by every tool and is not committed here, so build it once and copy it beside this file: 

git clone https://github.com/crmleaf/payroll-js.git
cd payroll-js && npm install && npm run build
cp dist/payroll.min.js /path/to/payslip-generator/demo/

The whole integration

One script tag and one element. It renders a labelled, accessible form, computes as you type, and shows the working with the statute behind each line. 

<script src="payroll.min.js"></script>
<payroll-payslip-generator></payroll-payslip-generator>

Starting values come from attributes

Named after the calculator's own parameters, hyphenated. Useful for pre-filling from a CMS field or a query string. 

<payroll-payslip-generator employee-name="Asha Menon"></payroll-payslip-generator>

Or a plain div

Most WYSIWYG editors drop a tag they do not recognise but leave a div with a data attribute alone, so both forms work. 

<div data-payroll="payslip-generator"></div>

Payslip Generator is part of the CRMLeaf payroll tools. The arithmetic and the dated statutory rate tables live in crmleaf/payroll-core; this package is the thin skin around one calculator. See the readme for the Composer and npm routes.

A calculation library, not tax advice. Verify against your own compliance obligations before relying on a figure for a filing.
